Legend: *live* = what the anon role gets from the production project right now (HTTP status and row count from `qa/output/schema/anon-table-probe.txt`); *SELECT[...]* = the policy that decides visibility, from replaying every migration on stock Postgres (`qa/output/schema/rls-policies.txt`). ## Flows

Hand-maintained. Each flow names the screens it crosses and the backend calls that can fail silently along the way. "Paid" marks a step that spends on a provider (TTS, ASR, LLM, Stripe) and should be exercised once by hand, not by the crawl.

### Learner

1. **Sign up → onboarding.** `/auth` (signup tab) requires a beta invite code: `verify_invite_code` RPC → `auth.signUp` (email confirmation is ON in the project, so the account is unusable until the link is clicked) → `redeem_invite_code` RPC → `/onboarding` (dialect, level, interests → `profiles`) → `/`. Google OAuth is enabled as an alternative. `/reset-password` handles the recovery link. `/login/id` is the ID-number path for reviewers (`access-credentials`).
2. **Placement.** `/placement` (`placement-quiz`, paid LLM) and `/placement/c-test` (auth; `reading-passage`, paid) write `placement_results` / `profiles.cefr_level`.
3. **Home and Today.** `/` is the feed (`discover-feed`, phrase of the day, daily challenge card, streak); `/today` is the queue (`useTodayQueue`: due reviews, weekly goals, recommendations, daily story). Both render for signed-out visitors with calls to user-scoped tables returning empty.
4. **Choose → Skill hubs.** `/choose` → `/skills/listen|read|speak|write` — static link hubs into everything below.
5. **Curriculum.** `/curriculum` (`curriculum_stages` → `lessons` → `lesson_progress`) → `/learn/:lessonId` (vocabulary, sound spotlight, sequence; `flashcard-audio` playback) → `/quiz/:lessonId` → progress + XP.
6. **Review (SRS).** `/review` (due `word_reviews` / `user_vocabulary`, FSRS-6 scheduling, `flashcard-audio`), `/review/my-words`, `/review/my-phrases` (`user_phrases`), `/my-words` (list, Anki import to `anki_import_batches` + `flashcard-audio`/`flashcard-images` uploads, "Find roots" → `enrich-word-roots` paid).
7. **Discover video.** `/discover` (published `discover_videos`, likes, ratings, CEFR) → `/discover/:videoId`: YouTube iframe or TikTok embed + hidden audio resolved from the **private** `video-audio` bucket via signed URL (needs a storage SELECT policy the learner does not have — see report), synced transcript (line + word timings), tap-a-word → `user_vocabulary`, chunk capture → `user_phrases`, slow listen, shadow tab (`score-shadow-attempt`, paid ASR), report (`report-content`). `/liked-videos` lists likes.
8. **Transcribe / tutor upload.** `/transcribe` (record or upload → `munsit|soniox|deepgram-transcribe`, paid; saves to `saved_transcriptions`) → `/my-transcriptions`. `/tutor-upload` uploads to `tutor-audio-clips` then `classify-tutor-segments` (paid LLM, unguarded — see report).
9. **Translate.** `/translate` (`translate-text`, `ask-translation`, paid; `saved_text_translations`) → `/translate/saved`; `/how-do-i-say`, `/dialect-compare`, `/bridge` (MSA ↔ dialect, `convert-to-fusha`).
10. **Set phrases (chunks).** `/set-phrases` (published `set_phrases` by `set_phrase_occasions`, saves to `user_set_phrases`) → `/set-phrases/practice` (`generate-set-phrase-quiz` paid LLM; spoken answers → `score-set-phrase-voice`, paid ASR, unguarded) → `/set-phrases/review`.
11. **Speaking.** `/pronunciation` (`azure-pronunciation`, paid), `/monologue` (`monologue-prompts`, `score-monologue`, paid), `/conversation` (live voice: `realtime-session-token` → WebRTC to OpenAI; text: `free-chat`), `/native-feedback` (credits via Stripe → `native_feedback_requests`), `/clips` (word clips from `published_clips`).
12. **Listening.** `/listening` (`listening-quiz` paid), `/listen` → `/listen/:id` (episodes in `listen_episodes`, audio from public `listen-audio`, plays counted by `increment_listen_play_count`), `/alphabet/sounds` (perception training → `user_perception_progress`).
13. **Reading and stories.** `/reading` (`reading-passage`, `reading-qa` paid), `/reading-library` → `/reading-library/:id` (`authentic_stories` + lines), `/stories` → `/stories/:storyId` (`interactive_stories`, `story_scenes`, `story_progress`), `/today/story` (`generate-daily-story`), `/souq-news` (`souq-news`, quiz), `/culture-guide` (`culture-guide` chat), `/bible*` (role-gated by `has_bible_access`).
14. **Writing and grammar.** `/write` (`writing-coach` paid), `/grammar` (`grammar-drill` paid, `record-grammar-outcome` → `user_concept_mastery`), `/mistakes` (`learner_errors`, `mistake-drill` paid).
15. **Games and social.** `/vocab-games`, `/daily-challenge` (`daily_challenges`, completions), `/battles` → `/battles/:battleId` (`vocab_battles`, realtime), `/leaderboard` (`leaderboard_profiles` view, `user_xp`, `review_streaks`), `/friends` (`user_follows`, streak visibility), `/profile` (achievements, badges), `/analytics` (SRS stats, production gap).
16. **Alphabet.** `/alphabet` → `/alphabet/:letterCode` → `/alphabet/checkpoint/:index` (auth; `record_checkpoint` RPC → `user_checkpoint_progress`, `user_letter_progress`).
17. **Account and billing.** `/me` hub, `/settings` (avatar → public `avatars`, push subscription, dialect, delete account), `/pricing` → `create-checkout` (Stripe) → return → `check-subscription` → `customer-portal`; referral code share (`referral`).
18. **Share-in.** `/share` and `/share-target` (PWA share target → `ingest-shared-video` / `screen-shared-content`), `/meme` (`analyze-meme` paid, `meme-uploads`), `/learn-from-x` (`scrape-x-post`, unguarded).
19. **Ask AI (global).** The floating assistant on every page: `assistant-chat` (SSE), `assistant-tools`, page context, saved conversations (`saved_chat_conversations`, `/saved-chats`), learner memory.

### Staff

20. **Admin sign-in** `/admin/login` → `/admin` dashboard (counts via `count: "exact"` on several tables).

25. **Chunks and dialect rules.** `/admin/set-phrases`, `/admin/chunks` (mine from reviewed transcripts), `/admin/dialect-rules` (`draft-dialect-rules`, violations).
